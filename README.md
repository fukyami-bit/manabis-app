# manabis-app

マナビス新松戸校の業務アプリ。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | 面談系アプリ（単体HTML）。面談スケジュール表の自動作成とターム面談の日程設定 |
| `gas/` | 来校管理システム（Google Apps Script） |
| `docs/` | 要件定義書と導入手順 |
| `test/` | 来校管理システムのテスト（Node.jsのみ・依存なし） |

## 来校管理システム

生徒がQRコードからフォームを送信すると来校登録が完了する。スタッフの転記作業をなくし、
正確な来校時刻を記録する。

- [要件定義書](docs/来校管理システム要件定義.md)
- [導入手順](docs/来校管理システム導入手順.md)

| ファイル | 役割 |
|---|---|
| `gas/code.gs` | サーバ側。データの読み書きと遅刻・要電話の判定 |
| `gas/student.html` | 生徒用フォーム（スマホ・QRから開く） |
| `gas/staff.html` | 受付画面（来校一覧・ファイル配布・欠席登録・取り込み） |

```sh
node test/backend.test.js    # 44件
node test/import.test.js     # 15件
```
