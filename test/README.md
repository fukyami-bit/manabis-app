# テスト

Node.js だけで動く。依存パッケージなし。

```sh
node test/backend.test.js    # gas/code.gs のロジック（36件）
node test/import.test.js     # gas/staff.html のExcel取り込み（15件）
```

## backend.test.js

GASの実行環境をメモリ上に再現して `gas/code.gs` を読み込む。
`SpreadsheetApp` は2次元配列で代用し、`Date` は固定時刻（2026-10-05 14:30 JST）に
差し替えてあるため、遅刻判定や要電話アラートの時刻依存ロジックを再現できる。

検証している主な項目

- ブース範囲（1-2 / 3-70 / 71-90 / 101-120）と区分の判定
- 名簿・予約の取り込みと、再取り込み時に重複しないこと
- 認可（合言葉なしは拒否、ページ鍵による照会回数の上限）
- 生徒は代理を名乗れず、重複登録を強行できないこと
- 予約時刻から基準を超えた登録が「遅刻」になること
- 日付が変わっても過去のログが消えないこと（要件 D-1）

## import.test.js

`gas/staff.html` から取り込み用の関数（`xlDate` / `xlTime` / `mapCols`）を
抜き出して評価する。実装を二重に持たないため、本体を直せばテストも追従する。

本部システムのエクスポートの実際の見出し行を埋め込んであり、列の対応付けが
壊れていないかを検証する。氏名カナや保護者氏名を氏名と誤認しないことも確認する。
